# Advanced-EM: Digital Coding Metasurfaces

This repository contains MATLAB scripts and documentation for simulating digital coding metasurfaces, originally developed as an end-semester presentation for the EE7500 course. The project explores far-field radiation patterns, beamforming, and array factor properties across 1-bit, 2-bit, and dynamic space-time coding formulations.

## 🚀 Overview
Digital coding metasurfaces allow for the control of electromagnetic waves through programmable phase coding. This repository provides programmatic models to calculate radiation intensity, visualize far-field patterns, and verify key principles like the convolution theorem for metasurface arrays. It also extends into time-varying coding to analyze frequency harmonics and dynamic beam steering.

## 📁 Project Structure
*   **`config.m`**: A class definition file that stores global constants for the array simulation. It defines parameters such as the 8.6 GHz operating frequency, the 8x8 array grid size (M=8, N=8), wave number, spatial spacing (Dx and Dy), and the 1000-point matrices for spherical coordinates theta and phi.
*   **`simulation.m`**: Contains the core simulations for static 1-bit and 2-bit metasurfaces. It calculates far-field values based on dipole element factors and phase shifts (e.g., 0 and $\pi$ for 1-bit; 0, $\pi/2$, $\pi$, and $3\pi/2$ for 2-bit). It also explicitly verifies the convolution property of the array factor by combining a "Plus Code" and a "Gradient Code" into a "Net Code".
*   **`space_time.m`**: Handles space-time coding simulations by generating 3D matrices (space and time) with 8 time slots. It computes the Fourier coefficients to extract the effective static amplitude and phase codes for individual harmonics (m = -3 to 3). It also includes functionality to generate a time-lapse `.mp4` video showing the 1-bit coding states over time.
*   **`Endsem_report.pdf`**: This document contains the comprehensive write-up, theoretical background, and mathematical proofs required to understand the underlying mechanics of the simulations.

## ✨ Features and Capabilities
*   **Far-Field Pattern Modeling:** Functions to compute and plot both 2D and 3D far-field radiation patterns based on customized grid codes.
*   **Space-Time Harmonic Analysis:** Mathematical extraction of amplitude and phase codes for specific frequency harmonics generated by time-varying reflection coefficients.
*   **Automated Plotting & Video Generation:** Generates comprehensive visualizations, including heatmaps of metasurface codes, 3D radiation lobes scaled in dB (floored at -40 dB), and an animated video (`spacetime_metasurface_1bit.mp4`) of the coding sequences.

## 🛠 Prerequisites and Setup
The code relies on standard MATLAB libraries. Before running `simulation.m` or `space_time.m`, you must manually create the following directory structures in the project root to store the generated plots and media:
*   `./plots/one_bit`
*   `./plots/two_bit`
*   `./plots/space_time_amp`
*   `./plots/space_time_phase`
*   `./plots/space_time_2D_far_field`
